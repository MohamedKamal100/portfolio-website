# Portfolio Website - Implementation Plan

## Structure
- index.html (main page)
- style.css (all styles)
- script.js (interactions)
- images/ (generated images)
- resume.pdf (placeholder)

## Sections
1. Navbar (sticky, dark mode toggle)
2. Hero (animated, typewriter effect)
3. About (profile image, bio)
4. Skills (animated progress bars + cards)
5. Projects (filterable cards)
6. Resume (download button)
7. Contact (validated form)
8. Footer

## Bonus Features
- Dark/Light mode toggle
- Smooth scrolling
- Scroll animations (Intersection Observer)
- Scroll-to-top button
- Loading animation
- Skill progress bars
- Contact form validation
- Social media icons
- Typewriter hero text
